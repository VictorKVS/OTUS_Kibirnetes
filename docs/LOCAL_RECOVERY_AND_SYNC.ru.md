# Восстановление Minikube и синхронизация локальной лаборатории

Это справочная инструкция, а не подтверждение изменений компьютера.

## Обнаруженные неисправности
На 14 октября 2026 года запуск Minikube 1.39.0 не завершён. Профиль otus-k8s ссылается на отсутствующий файл конфигурации машины. Kubernetes-контекст не появился. Библиотека PyYAML установлена, но файл локального аудитора ещё не был скачан на диск G.

## Безопасный порядок действий
1. Собрать сведения о профилях Minikube, состоянии Docker, списке контейнеров и существовании конфигурации машины.
2. Проверить, что предполагаемый к удалению профиль — одноразовая учебная среда.
3. Удалять только именованный профиль после проверки и согласования. Не выполнять массовую очистку образов или томов Docker.
4. Если ошибка Windows icacls повторится, зафиксировать полный диагностический вывод и остановить автоматическое исправление.
5. Синхронизировать GitHub в отдельную копию; не перезаписывать существующие материалы курса на диске.
6. Только после проверки наличия файлов запустить статический аудит Kubernetes YAML и изучить отчёт.

Команды PowerShell полностью сохранены в исходном документе: [LOCAL_RECOVERY_AND_SYNC.md](LOCAL_RECOVERY_AND_SYNC.md).

## Защита данных
Существующие контейнеры и образы FATHER нельзя удалять ради учебного Minikube. Ключи доступа, kubeconfig, закрытые данные и секреты не загружать в публичные репозитории.

## Результаты проверки
Для каждого действия в будущем фиксировать идентификатор операции, время, пользователя, версию инструмента, код результата, журнал ошибки и контрольный тест. Пока автоматический журнал не внедрён.
